## Rules & Discipline

硬性约束

- **禁止硬编码密钥**：一旦检测到 API Key 出现在代码中，立即拦截。
- **强制测试覆盖率**：规定新代码必须有 80% 以上的测试覆盖率，否则不予通过。
- **Git 提交格式**：自动将改动格式化为符合 Conventional Commits 规范的日志。
